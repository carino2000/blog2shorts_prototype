# 디자인 시안 작업 기준 (팀 회의용 PoC)

2026-11-01 사용자 지시. 팀 회의에서 고르기 위한 시안 모음이다. 브랜치 `design-variants`에서 작업한다. 합치는 시점은 사람이 정한다.

## 목표

색만 다른 스킨이 아니라 **문구·카드·배치·크기·흐름의 표현까지 다른, 각각 완성된 웹 애플리케이션처럼 보이는 시안**을 만든다. 개수 제한은 없고, 사용량 한도까지 아래 순서로 하나씩 완성한다.

시안을 절반만 만든 채 다음으로 넘어가지 않는다. 적게 완성하는 것이 많이 미완성인 것보다 낫다.

## 구조

- 왼쪽 아래 작은 전환 패널에서 시안을 고른다. 주소에 `?v=시안id`로 남아 링크를 공유할 수 있고, 이동해도 유지된다.
- `src/variants/<id>/`에 시안별 화면 5개(입력, 처리 중, 대본, 장면 편집, 렌더·결과)와 그 시안 전용 컴포넌트·CSS 토큰을 둔다. 토큰은 시안 범위로 묶어 서로 섞이지 않게 한다.
- 현재 화면은 `base` 시안으로 그대로 둔다.
- 데이터·동작은 공유한다: `api/queries`, `lib/`(URL 검증, 길이 계산, 렌더 기준값, 품질 저장). 시안에서 API를 직접 부르지 않는다.
- 시안은 필요할 때만 불러오도록 지연 로딩한다.
- 회의는 mock으로 진행한다(실제 API 비용 0). 실제 백엔드 연결도 깨지지 않아야 한다.

## 모든 시안이 지킬 것

- 기능 유지: URL·본문 입력, 처리 단계, 요약·대본, 장면 문구·이미지·모션 수정, 업로드, 품질 선택, 렌더 단계, 재생·다운로드, 재시도, 오류와 빈 상태.
- 계약·백엔드 변경 금지. 새 npm 패키지 금지. 웹폰트는 Google Fonts `<link>` 또는 이미 있는 Pretendard.
- 영상 미리보기의 자막 크기·위치는 `lib/render.ts` 값 그대로. 실제 렌더와 달라지면 안 된다.
- 375·768·1280px에서 가로 넘침·잘림 없음, 글자 대비 4.5:1, 터치 44px, 키보드 포커스 표시, `prefers-reduced-motion` 존중.
- 다크 전용·라이트 전용 시안은 허용한다(시스템 설정을 따르지 않아도 된다).
- 없는 사실을 지어내지 않는다: 가짜 사용자 수, 후기, 고객사 로고, 처리 시간 약속, 가격 금지. 로그인·요금제·스톡 등 범위 밖 기능을 화면에 넣지 않는다.
- 참고 서비스의 화면·로고·문구를 복제하지 않는다. 원칙만 가져온다.
- `frontend/CLAUDE.md` 5장의 토큰·모서리·그림자 값은 `base`에만 적용된다. 시안에는 위 항목이 우선한다.
- 흔한 AI 생성 사이트의 습관을 피한다: 보라색 그라디언트, 모든 곳의 둥근 카드와 아이콘 원, 제목 중앙 정렬 + 카드 3개의 판박이 구성.

## 시안 목록 (이 순서로 제작)

| id | 이름 | 인상 | 차별점 |
|---|---|---|---|
| `night` | 야간 편집실 | 차분·전문가 | 다크. 큰 미리보기가 중심, 아래에 장면이 타임라인처럼 이어짐. 선택 장면만 옆 패널에서 편집 |
| `press` | 흑백 인쇄 | 흑백·지적 | 명조 큰 제목, 가는 괘선, 잡지 조판. 원문과 대본을 지면처럼 나란히 |
| `ledger` | 단정한 안내 | 정갈·친절 | 한 번에 질문 하나인 세로 단계형. 큰 글자와 넓은 여백, 짧고 친근한 문구 |
| `command` | 작업 콘솔 | 세련·고밀도 | 왼쪽 내비게이션, 표 형태 장면 목록, 인스펙터, 단축키 안내 |
| `reel` | 빅 릴 | 화려·대담 | 초대형 타이포, 강한 색면, 세로 영상 카드를 크게 넘기는 편집 |
| `paper` | 종이 공방 | 따뜻·차분 | 미색 종이, 메모지 같은 장면 카드, 부드러운 어조 |
| `grid` | 스위스 격자 | 이성적 | 12단 격자, 큰 번호, 한 가지 강조색, 비대칭 배치 |
| `zine` | 굵은 진 | 개성·강렬 | 굵은 테두리와 단단한 그림자, 형광 강조. 대비 기준은 그대로 지킴 |
| `gallery` | 전시관 | 초미니멀 | 순수 흑백 산세리프, 극단적 여백. 화면마다 한 가지만 전시하듯 크게 보여 줌. 테두리와 카드를 거의 쓰지 않음 |
| `cinema` | 상영관 | 영화적 | 상하 검은 띠의 와이드 화면, 포스터 같은 제목, 크레딧처럼 올라가는 대본, 시사회 같은 결과 화면 |
| `broadcast` | 방송 부조실 | 현장감 | ON AIR 표시, 큐시트 형태 장면 목록, 송출 모니터와 프리뷰 모니터 2분할 |
| `blueprint` | 설계 도면 | 기술적 | 청사진 바탕, 가는 선과 치수 표기, 부품표 형태 사양, 도면 번호 체계 |
| `soft` | 부드러운 유리 | 경쾌·현대적 | 밝은 파스텔 바탕, 반투명 층, 큰 곡률, 말풍선 흐름의 대본. 보라색 그라디언트 금지 |
| `desktop` | 옛 PC 책상 | 놀이·복고 | 창과 제목 표시줄로 구성한 작업 공간, 장면을 파일 아이콘처럼 다룸. 실제 OS 화면을 베끼지 않음 |
