### 1.1 추진 배경

- 블로그 1건을 숏폼으로 바꾸려면 내용 정리 → 대본 작성 → 장면 분할 → 이미지 선정 → 음성 생성 → 자막 제작 → 영상 편집의 반복 작업이 필요함
- 사람이 전부 수행하면 1건당 많은 시간이 들기 때문에 생성형 AI로 제작 과정을 자동화하려는 것

## 2. 처리 파이프라인 (7단계)

| STEP | 단계 | 입력 | 출력 |
|---|---|---|---|
| 01 | 블로그 입력 | URL / 텍스트 | 원문 |
| 02 | AI 내용 분석 | 원문 | 핵심 정보 |
| 03 | 대본 생성 | 핵심 정보 | 30~60초 분량 대본 |
| 04 | 장면 구성 | 대본 | Scene 단위 분할 |
| 05 | 이미지 배치 | Scene + 블로그 이미지 | 장면별 시각자료 |
| 06 | TTS · 자막 | Scene 대본 | 음성 / Caption |
| 07 | 영상 완성 | 이미지 + 음성 + 자막 | 영상 (미리보기 / 저장) |

### 2.1 MVP 구조

```
사용자 ──(블로그 URL 입력)──▶ FRONTEND (URL / 콘텐츠 입력 화면)
                                   │
                                   ▼
                          AI CONTENT ENGINE
              ① 분석(핵심 내용 추출) → ② 대본(숏폼 스크립트)
              → ③ 장면(Scene 구성) → ④ 이미지(시각자료 배치)
              → ⑤ TTS(AI 음성) → ⑥ 자막(Caption 생성)
                                   │
                                   ▼
                     OUTPUT: 9:16 숏폼 영상 (미리보기 · 다운로드)
```

## 5. 기대 효과 (페이지의 페르미 추정)

| 구분 | 수작업 | AI 자동화 |
|---|---|---|
| 콘텐츠 분석 | 10분 | — |
| 대본 | 10분 | — |
| 이미지·장면 구성 | 15분 | — |
| TTS·자막 | 10분 | — |
| 영상 편집 | 15분 | — |
| 콘텐츠 입력 | — | 1분 |
| AI 처리 | — | 3분 |
| 결과 확인 | — | 3분 |
| 일부 수정 | — | 3분 |
| **합계** | **약 60분** | **약 10분** |

- 1건당 약 50분 절감 (약 83% 감소)
- 월 100건 기준: 5,000분 ≈ 83시간 ≈ 8시간 근무 기준 약 10.4일
- 페이지 단서: 영상 길이, 수정 횟수, API 처리속도, 콘텐츠 난이도에 따라 달라질 수 있음

[해석] "AI 처리 3분"이 사실상의 처리 시간 목표치로 읽힘. 명시된 성능 요구사항은 아님.
