## 확인한 것

- 한글 자막: 장면 가운데 프레임 5장(`frame_s1..5.png`)을 열어 확인. 깨짐 없음, 흰 글자 + 검은 외곽선, 하단에서 위로 떨어진 위치, 가운데 정렬. 폰트는 `fonts/NotoSansKR-Bold.ttf`(패밀리 `Noto Sans KR`, Bold)를 작업 폴더에 복사해 `fontsdir=fonts` 상대 경로로 지정
- 레이아웃: 가로·정사각 이미지는 흐린 배경 위에 잘리지 않고 올라감
- 모션 5종: 장면 첫/마지막 프레임 비교
  - zoom_in: 가운데 원 폭 140→156px(×1.11)
  - zoom_out: 이미지 위쪽 테두리 y 71→164(축소)
  - pan_left: 원 중심 x 604→479
  - pan_right: 원 중심 x 476→602
  - none: 테두리 y 165→165(고정)

## 발견한 문제와 조치

- **색 범위**: 명령을 문서 그대로 쓰면 JPEG 입력의 풀 레인지가 남아 최종 `pix_fmt`가 `yuvj420p`가 된다(`-pix_fmt yuv420p`를 줘도). 일부 플레이어·SNS에서 색이 다르게 보일 수 있어, 필터 끝에 `scale=out_range=tv,format=yuv420p`를 붙여 `yuv420p`/`tv`로 맞췄다. B9 `render.py`에도 같은 줄이 필요하다.

## 확인하지 못한 것

- zoompan 흔들림(jitter): 영상을 재생해서 눈으로 보지 못했다. 프레임 수치로는 모션 방향·크기만 확인
- 일반 플레이어 재생: 직접 재생해 보지 않았다(ffprobe로 표준 h264/aac/yuv420p만 확인)
- 메모리 사용량: 재지 않았다
